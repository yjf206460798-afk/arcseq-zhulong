**改了什么**（先看 `BA-orbit.png`、`AB-c2-tip.png`、`BA-az030-12x-eye.png`、`TARGETS.png`）
1. 停机闭眼：`nose.IRIS_CLOSED = True`，钛虹膜尖盖合拢成针尖，琥珀镜片退到尖盖后只露一圈。俯 / 侧 / 前三视叠图里针尖与 C2 机头尖重合（`OVERLAY-c2-tip-*`）；睁眼留到 Z4 的开合机构。
2. B 机身压暗到哑光石墨灰：build.mjs `PBR.hull` 0.62 / 0.34 / 3.2 → **0.8 / 0.34 / 0.75**（金属度 / 粗糙度 / 基色增益），机腹 `belly` 0.45 / 0.45 / 3.4 → 0.6 / 0.4 / 2.4。基色压暗、金属度提高：明度主要来自工作室环境反射，大平切面上有一条由亮到暗的反射渐变（`TARGET-2-nose-B`），读成金属不读成塑料。
