# Z1 复刻样板 · R4（门禁前补一轮，待作者门禁）

**画法默认 B**：`dist/index.html`（页面「图纸」按钮运行时切 A）；`dist/drawing.html` 只有 A。档位按 VISUAL_TARGET「精度分配」：满 = 满精度，中 = 中精度。

**改了什么**（先看 `BA-orbit.png`、`AB-k1-cut.png`、`CLOSE-az030-12x-eye.png`、`CLOSE-az060-10x-pilot-front.png`）
1. 飞行员（占位：作者已把銜燭转到「附件 · 銜燭」会话，Z1 不再以它为门禁）：头盔按 9.1.1（盔顶眉骨、窄面罩、收起的暗琥珀遮光面罩、镀铬颈环）；身体先平滑掉胸肌腹肌，摆姿后 delta mush + 跨沟，再外扩成服装壳；手套 / 靴 / 领口平面切开，接缝是网格与平面的交线（肩、腋下无锯齿）；胸前「銜燭」繁体 2.4 cm。
2. 外观（满）：光窗读成眼睛——停机睁眼，圆形琥珀镜片 + 暗瞳仁 + 亮钛虹膜圆光圈（`12x-eye`）；五处口盖做成凹缝 + 六角紧固件（`6x-hatch`）；结构环缝遇口盖断开；探头、静压孔、天线、姿控格栅见 `4x-details`（R2 已有，B 的分割线改成深色细缝后才读得出）。
3. 剖面明暗（座舱满、航电舱与座舱后设备舱中）：远侧每格一块浅灰内衬壁板 + 座舱侧壁同材质提亮（`fill` 平光）；零件、线按离剖切面远近压暗；内部折边降一级。中精度区到此为止。
4. 性能：线条分级挪进顶点着色器（每条边一个实例）；发光通道不再画线层和不发光的内部件。
5. B 右侧面板条纹：根因是蒙皮的顶点 AO 被大三角形拉成竖条；蒙皮只用逐纹素烘的贴图 AO，口盖板、内衬这类只有几个顶点的平板不烘顶点 AO（`aoFlat`）。连带修掉：无 uv 的件错用蒙皮 PBR 法线（屋面口盖发暗）、机腹鳞片瓦比地台还暗（补光）。
