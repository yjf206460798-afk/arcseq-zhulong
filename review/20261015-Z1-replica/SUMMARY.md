# Z1 复刻样板 · R3 反馈七项 + 按 K1 零件表补建（待作者门禁）

**改了什么**（看 `AB-k1-cut.png`、`AB-oblique.png`、`CLOSE-az090-4x-cockpit-cut.png`、`CLOSE-az100-7x-pilot.png`）
1. 剖面封口：切开的件画实心剖面（亮一档 + 极淡斜线）；4 cm 蒙皮剖面带（含眉骨、遮光盾槽与衬板）；隔框每约 0.5 m（K1 表里的框站位 + 补齐）、远侧桁条、龙骨 / 背脊纵梁。
2. 填满：按作者确认的零件表补建 457 件（`blender/zl/k1table.py`）；管线按 K1 路径重铺，两端接零件 / 结构 / 管网（悬空 0），同一管网同一深度；**填充度 A 44.5%（K1 的 89%）/ B 52.1%（105%）**（K1 49.8%，指标 ≥ 80%，`COVERAGE.txt`；A 的箱面原来暗到和底色分不开，内部色板按 K1 的中灰提亮）。穿出蒙皮 0 件。
3. 部件本体：盒（倒角、面板凹缝、固定耳、四角螺栓、插头、小铭牌），圆柱件端盖 + 箍带。
4. 清理：无字引线默认隐藏（`__arcseq.callouts(true)` 打开）；画叉方框已去；右上角件都在机身内、有托架。
5. 座舱：驾驶员换成 CC0 人体基础网格按骨架摆姿（身高 1.74 m、椅背 30°、膝内角 112° 踩脚蹬、手握侧杆 / 油门，头盔顶离座舱盖 7.5 cm），按 X1 软态穿服装（平面切口接缝、腿腹气囊、护膝、扁织带挽具、脐带接口、暗朱红脊线），头盔按 DESIGN 重做（眉骨、窄面罩、收起的暗琥珀遮光面罩）；平视显示器、屏幕调暗，开关板只留一排指示灯发光；座舱盖剖面为青色细边 + 半透明；红灯单元缩小降饱和。
6. 光与色：机库背景深蓝黑渐变；三级线宽 0.9 / 0.55 / 0.35 px（小件一律 L2）；光窗琥珀、屏幕青光作点缀。
7. A/B：B 加盒投影反射（平切面上有渐变）、主副光对比、轮廓光、AO 1.8 次幂；3/4 斜视并排见 `AB-oblique.png`。

**数字**：外形 4.2 万三角形；剖视内部模块 20.6 万三角形 / 6.3 MB（按需加载，预算 ≤ 22 万 / 8 MB，写进 BLENDER.md）。页面 A 3.0 MB、B 3.5 MB。每帧脚本（软件 GL）：外形 390 宽 / DPR 3 / 4× 节流 A 10.2 ms、B 10.6 ms，1440 宽 2.5 ms；剖视 390 宽 25.5 ms、1440 宽 8.8 ms——手机条件超出 5 ms 参考，主要是每帧在 JS 里给 1300 多个内部件的边定级（下一步改成转角变化超过阈值才重算，或挪进着色器）。

**还不对的地方**
- 侧杆、油门、脚蹬按真人够得着的位置放，比 K1 靠后约 0.4 m（K1 的人画小了约 0.65 倍）；整体看我们的驾驶员比 K1 小一圈。
- K1 里内壁是成片的浅灰壁板，我们远侧是暗内壁 + 框与桁条，剖视读起来更像骨架；座舱远侧壁板偏黑。
- 服装是中等精度：接缝在肩、腋下仍有小锯齿；「銜燭」铭文未上身；手指是一体握拳。
- K1 顶边的朱红长条是已知错误，没建；零件表里两行（O005、O006）放不进截面，跳过。
- 云端是软件 GL，真机 GPU 数字待发布前实测。
