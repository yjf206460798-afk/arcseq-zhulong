# Z2 · R5：300 px 缩略图、原创性复查、版式样图、独立审查

不改模型（几何同 R3/R4）。先看 `THUMB-silhouette.png`（纯灰剪影 + 无转台在轨构图）、`THUMB-300.png`（成品画法四机位）、`../20261015-Z2-layout/LAYOUT-desktop.png` / `LAYOUT-mobile.png`。

**300 px**
- 大气形态：剪影三个机位都读成“针尖机头 + 三角翼 + 双垂尾”的空天战机，60° 高俯最好。成品画法（B）里扇骨的 11 道台阶线在 300 px 下成摩尔纹，最亮、最抢眼。
- 剑形态：只有 60° 高俯能勉强读成剑；30° 默认机位读成“带尾翼的飞镖”，低平机位读成“方盒 + 裙边”。主因：后机身是等宽方箱、扇骨窄带在 s 9.7 以钝头外跳再在 s 15.1 收回（一道“腰”）、剑格后掠且在机身顶上（像尾翼 / T 尾）。

**原创性复查**：只有机头段时的“楔形星舰”印象，整机后没有消失——剑形态在轨构图（匕首形平面 + 平底 + 抬高的后段方箱 + 顶上一对水平板）仍是那一类太空战舰的特征组合；大气形态“一个轴心 + 一圈放射扇骨”的翼，独立审查认为容易联想到机甲动画里的放射状羽刃背翼。针尖机头、鸭翼、外倾双垂尾、下垂翼尖鳍是航空语汇，没有对应到具体作品。引擎加了无转台的 `orbit` 环境（入轨构图不再有转台挡住地球弧）。

**版式样图**（`review/20261015-Z2-layout/`，`scripts/layout-sample.py` 从当前构建截图）：左操作、中模型 + 5 个编号引线、右三视图与四个特写入口、图纸外框；手机版模型在上、四个标签的抽屉、引线只留编号。还差：中栏画布应透明铺满中栏、镜头拉近；右栏三视图应是线稿并补尺寸线；手机版空白多。

**独立审查**（未参与制作的子代理，全文要点）——**不建议现在进门禁**，进之前要改：
1. 剑形态剪影：剑身连续渐收，消掉扇骨带的钝头和腰；剑格朝剑身那条边垂直、降到剑身中面；后机身去掉方箱。
2. 证明不穿模、不消失：41 个采样之间零件一步走 0.35～0.51 m，而间隙只有 4～33 mm——检查要在近距离件对上加密 / 保守推进，全程查“埋进机身”；补逐姿态的正交侧视与仰视（棱线下折的鸭翼、边条、进气门在俯视里看不见）。
3. C3 前视：叠图取景裁掉了模型下半截；前视偏差（截面约 C3 的 1.5 倍宽、2.5 倍高）与剑格在机身顶面都没写进 8.8。
4. 入轨构图：去掉转台、换机位后再复查原创性（转台已去掉，本页右列）。
5. 补纯灰剪影 300 px（已补，本页左三列）。
另有：主翼只靠一根轴毂传力不可信（建议加弧形导轨 / 托架）；轮毂像一根桩；后缘边条铰线离蒙皮约 4 cm；剑形态翼尖鳍低于腹底 0.2 m（与“迎风面积最小”矛盾）；中后机身侧视偏深约 0.3 m。
