参考：网上一个程序生成的 3D 马车展示页（推文截图，作者转来）。**只借它的信息结构**（左操作、中模型、右图纸，零件编号引线跟着模型走），不借它的品牌、字体、配色和任何素材；画面仍是 ARCSEQ 的深色舞台。

## 导览模式（作者 2026-10-15 转来的对比视频启发）

一个「导览」按钮：镜头按章节自动走，每章左下角一行大字标题 + 一行小字说明，用户随时可以接管（拖动即暂停导览，松手后点「继续」）。复用 FIG.01 的演出导演（ActionDirector），章节就是演出里的段落。

- 整机导览：线框 → 外形 → 座舱（睁眼 / 闭眼）→ 透视 → 爆炸（显示“n 个零件”）→ 烛心 → 化剑 → 复位。
- 烛心导览：外壳上下掀开 → 线圈逐段亮 → 等离子柱点亮 → 马赫数自动扫过 0 → 2.5 → 6 → 真空（三模式依次切换）→ 合拢 → 点火。
- 实时读数面板（右下）：一个大数字 + 状态词 + 目标条，例如「马赫 2.4 · 吸气 · 风扇展开」，拖滑杆时数字追着目标走，不瞬变。
- 透视模式（X 光蓝线框）在导览里作为过渡章节使用，也可单独开关。
- 录制模式下导览就是宣传短片的分镜：一条导览 = 一条可发的视频。

## 手机版（宽 < 1100 px，性能基准 390 宽）

模型在上、占满宽；左右两栏折进底部抽屉，四个标签：演出 / 机构 / 视图 / 图纸。编号引线保留但只显示编号，点开再出名字。

## 主题

默认深色（天门深蓝黑，品牌固定色）；可切换浅色「图纸模式」（暖白纸底、深色线），两种主题共用同一套版式。

## 归属

- 引擎（`[kit]`，与机型无关）：编号引线层（地标点 → 屏幕坐标 → 引线与遮挡淡出）、实时三视图（正交线稿渲染到小画布、带尺寸线）、图纸外框与刻度、底部抽屉。
- 作品：按钮清单、地标点、规格数字、文案。
- 时机：版式线框在 Z2 期间先出一张静态样图给作者确认（不影响建模）；编号引线和实时三视图在 Z4 机构阶段落地；手机抽屉沿 ROADMAP Z6。
