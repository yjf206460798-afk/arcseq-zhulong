# Blender 管线（2026-10-15 云端实测可用）

## 已验证
- 云端容器可直接安装 Blender 的 Python 模块：`pip download bpy`（5.2.2 LTS，Python 3.13 版，约 400 MB），装进独立 venv，无界面后台运行。
- 实测一段机头试验件：脚本建模（截面放样 + 细分）→ Cycles CPU 渲染 960×540、48 采样、降噪，约 40 秒一帧 → 环境光遮蔽烘焙到顶点色 → 导出 GLB：零件名（如 `canopy`、`chine.l`）原样保留，AO 存为 `COLOR_0`。

## 规矩
1. **母版是脚本，不是文件。** 几何母版 = `blender/build.py`（加若干模块），运行一次就能从零生成全部模型；`.blend` 和 `.glb` 都是产物，不手改。作者想手调某处，改完由 Claude 把改动写回脚本。
2. **命名即接口。** 每个可动零件一个对象，名字与 Three.js 里的机构 id 一致（如 `wing.outer.l`）；转轴用空物体 `pivot.<id>` 表示，位置和朝向就是转轴。
3. **导出两份**：`assets/zhulong.glb`（网页用：已应用修改器、AO 在顶点色、贴图压缩）与 `assets/zhulong.json`（机构元数据：转轴、行程、地标点）。
4. **网页风格不变。** Three.js 读入 GLB 后照旧套用 ARCSEQ 的块面明暗与分级线条；硬边在 Blender 里标记（sharp edge），供线条层取特征边。
5. **渲染分工**：网页与演示录屏走 Three.js；海报、封面、特写镜头可走 Blender Cycles。两者用同一套配色卡和机位约定，避免风格打架。
6. **性能**：网页模型面数预算在 Z1 定；鳞片瓦等重复件用实例化；细节优先烘焙成贴图，不堆几何。

## Z1 实测（2026-10-15，机头段 look-dev）

- 安装：`python3.13 -m venv .venv && .venv/bin/pip install bpy pillow`（bpy 5.2.2 LTS；`.venv/` 不进仓库）。pip 版没有 Draco / MeshOptimizer 压缩库（导出时打印两行 ERROR，不影响导出）——网格压缩以后在 Node 端做。
- 母版：`blender/build.py` + `blender/zl/`（`util` 工具、`nose` 机头段、`bake` 烘焙与导出、`detail` 细节贴图、`render` Cycles）。做法写在 `docs/PATTERNS.md`「几何母版：Blender 建模脚本」「切面机身：位似放样」「顶点 AO 与烘焙细节贴图」。
- 时间（云端 4 核）：建模 0.2 s；顶点 AO + 贴图（位置 / 法线 / AO 三张 2048²）约 50 s；导出 0.1 s；Cycles 1600×1072 64 采样约 70 s，85 mm 景深特写 96 采样约 170 s。
- 面数：机头段 10.7k 三角形（其中鳞片瓦样片约 4.6k）。~~整机 ≤ 80k~~ 已按作者 R2 要求改为下面的预算。
- **网页面数预算（Z1 复刻样板定，作者 R2）**：常驻（外形，整机）约 30 万三角形；按需模块各自另算，打开时才加载：剖视内部每段 ≤ 22 万三角形、模块文件 ≤ 8 MB（Z2 整机体积样板：外形 5.8 万（58,127，机头段细节 4.4 万 + 中后机身、折扇主翼 24 片扇骨、垂尾、喷口等 1.4 万）；机头段实测 R4：外形 4.4 万（44,445）；内部 21.9 万（219,244），其中驾驶员 2.9 万（R4 服装壳 + 头盔细节）、隔框 1.5 万 + 螺钉 0.35 万、远侧内衬壁板 0.57 万（不加螺钉）；R3：内部 20.4 万）。重复件（鳞片瓦、铆钉）走贴图或实例；管件、螺栓这类件数多的小件做 8 边、不倒角；细节贴图机身每 7 m 左右一张 2048²（约 2.5 mm/纹素）。
- 导出：`export_extras`（自定义属性 → 零件元数据）、`export_vertex_color="ACTIVE"`（AO 颜色属性 → COLOR_0）、`export_apply`、材质只导出名字（`export_image_format="NONE"`），贴图另存 PNG。
- 页面体积：本段零件 JSON 1.8 MB + 贴图 0.8 MB 内联，整机前要改成二进制直读（见 DESIGN 8.2）。
