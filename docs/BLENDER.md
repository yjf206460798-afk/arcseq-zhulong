# Blender 管线（2026-10-15 云端实测可用）

## 已验证
- 云端容器可直接安装 Blender 的 Python 模块：`pip download bpy`（5.2.2 LTS，Python 3.13 版，约 400 MB），装进独立 venv，无界面后台运行。
- 实测一段机头试验件：脚本建模（截面放样 + 细分）→ Cycles CPU 渲染 960×540、48 采样、降噪，约 40 秒一帧 → 环境光遮蔽烘焙到顶点色 → 导出 GLB：零件名（如 `canopy`、`chine.l`）原样保留，AO 存为 `COLOR_0`。

## 规矩
1. **母版是脚本，不是文件。** 几何母版 = `blender/build.py`（加若干模块），运行一次就能从零生成全部模型；`.blend` 和 `.glb` 都是产物，不手改。作者想手调某处，改完由 Claude 把改动写回脚本。
2. **命名即接口。** 每个可动零件一个对象，名字与 Three.js 里的机构 id 一致（如 `wing.outer.l`）；转轴用空物体 `pivot.<id>` 表示，位置和朝向就是转轴。
3. **导出两份**：`assets/zhulong.glb`（网页用：已应用修改器、AO 在顶点色、贴图压缩）与 `assets/zhulong.json`（机构元数据：转轴、行程、地标点）。
4. **网页风格不变。** Three.js 读入 GLB 后照旧套用 ARCSEQ 的块面明暗与分级线条；硬边在 Blender 里标记（sharp edge），供线条层取特征边。
5. **渲染分工**：网页与演示录屏走 Three.js；海报、封面、特写镜头可走 Blender Cycles。两者用同一套配色卡和机位约定，避免风格打架。
6. **性能**：网页模型面数预算在 Z1 定；鳞片瓦等重复件用实例化；细节优先烘焙成贴图，不堆几何。
