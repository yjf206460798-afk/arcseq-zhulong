# 烛龙 · 机体设定

原创构想机。所有数值为设计值（估），建模时可按画面需要调整并在此记录。

## 1. 概念

| 项 | 设定 |
|---|---|
| 名字 | 烛龙（Zhulong）。《山海经》：“视为昼，瞑为夜。” |
| 定位 | 单座空天战机：跑道起飞，爬升冲出大气层进入近地轨道，再入后返回降落 |
| 核心卖点 | 收拢“化剑”：高超音速 / 再入时变为剑形态，迎风面积最小 |
| 总体意象 | 一把剑：前锐后重。前约 40% 是多面体切削的“刀刃”，后部是厚重的发动机段“剑格” |
| 神话元素 | 只藏在功能件里：机头光窗＝烛；座舱遮光盾＝眼睑；机腹防热瓦＝鳞；背脊推进器与散热口的排列＝龙脊；垂尾后缘带鳍的弧度 |
| 座舱 | 单座。设定上有 AI 副驾驶，负责系统与僚机，在读数行体现（如“僚机已释放 · 编队就位”） |
| 无人僚机 | 设定中有，背部载荷舱释放；放在后期阶段，不进第一版 |

## 3. 外形（以 `refs/concept/C2` 为准）

| 部位 | 设定 |
|---|---|
| 机身 | 乘波体：机腹完全平整；上表面大块切面、棱线分明；机头细长针状、略下垂 |
| 棱线边条 | 从机头沿两侧一路展开到机翼前缘；沿棱线一道极细朱红线（烛龙标志） |
| 机翼 | 曲折双三角翼：内段约 75°、外段约 55° 后掠；外段翼尖可下折，带小鳍 |
| 鸭翼 | 小型，位于棱线中段，可收进棱线槽 |
| 座舱 | 单座，低矮融入机身；前上方一道切削“眉骨”（C2 未画出，建模时补）；遮光盾沿滑轨从前方滑下盖住座舱 |
| 机头光窗 | 机头尖端圆形传感器光窗，虹膜式遮片；工作时透出一点暖琥珀微光 |
| 进气 | 机腹一道宽扁二元进气口，中间分流板；从上方完全看不见；可闭合 |
| 垂尾 | 双垂尾，长在尾部发动机段两外侧，外倾 |
| 尾部 | 两侧矩形二元喷口（吸气式）夹中央塞锥火箭喷口（C2 为锥形塞式，保留锥形） |
| 姿态推进器 | 机头、翼尖各一簇；背脊一排小推进器与散热口 |
| 背部 | 长条载荷舱门（僚机） |
| 机腹 | 整片防热瓦，**前后错叠的鳞片排列**（C2 画成六角蜂窝，建模时改为鳞片）；机翼前缘深色碳-碳 |
| 涂装 | 哑光石墨灰，标识极少；朱红棱线；再入时机腹鳞片缝隙泛琥珀光 |

## 4. 两种形态

| 部件 | 大气形态 | 剑形态（`refs/concept/C3`） |
|---|---|---|
| 鸭翼 | 展开 | 收进棱线槽 |
| 主翼 | 曲折三角翼 | 向后回转至与机身平行，外段向下折，贴住后机身两侧（收拢关系 C3 未交代，**Z1 必须设计清楚**） |
| 翼尖小鳍 | 立起 | 折平 |
| 垂尾 | 外倾立起 | 向外转平，伸出两侧成为“剑格”护手 |
| 座舱 | 可见 | 遮光盾合上（闭眼） |
| 进气口 | 开 | 闭合 |
| 朱红棱线 | 静止细线 | 从剑尖亮到剑格（开锋） |
| 剑的对应 | — | 机身＝剑身（三角形渐收，似古青铜剑 / 锥形重剑，**保留，不改平行刃**）；转平垂尾＝剑格；发动机段＝剑柄；塞锥＝剑首 |

C3 的侧视图把剑格画成上下竖片，与俯视、前视矛盾：**以俯视、前视为准（水平两片）**。

## 5. 化剑步骤（演出顺序，草案）

1. 鸭翼收进棱线槽；
2. 主翼向后回转至与机身平行；
3. 外翼段向下折，贴住后机身；翼尖小鳍折平；
4. 垂尾向外转平，成剑格；
5. 进气口闭合；遮光盾合上（闭眼）；
6. 开锋：朱红棱线从剑尖一路亮到剑格；
7. 塞锥火箭点火（淡蓝尾焰）。

反向「展剑」按相反顺序。转轴位置与先后顺序在 Z1 用正交俯视图逐步验证，确保任何中间姿态不穿模。

## 7. 演出

与「不周 · 世界设定」统一（作者 2026-10-15）：烛龙停在**四层天门**（卡门线，100 km），由电磁滑轨弹射到约 2 km/s 后点火入轨；返航时以剑形态再入，滑翔降落在**一层归墟港**的跑道。出击只用火箭模式，吸气与冲压留给返航。

| 演出 | 步骤 |
|---|---|
| 出击 · 入轨 | 托架转正对准滑轨 → 锁臂松开、脐带脱落 → 气闸门打开（门外是黑天与一弧地球）→ 电磁弹射（滑轨线圈逐段亮起向后流走）→ 脱离托架、塞锥点火（淡蓝尾焰）→ 远景：一道光点离开天柱 → 闭眼 → 姿态推进器调姿入轨 |
| 化剑 | 在轨执行任务时化剑（切开或推离威胁天柱的大型碎片，世界设定原文），步骤见第 5 节；高潮为开锋 |
| 返航 | 剑形态再入，机腹鳞片缝隙泛琥珀光 → 展剑 → 睁眼 → 进气门重开、风扇保持折起（冲压，6 → 2.5 Ma）→ 风扇展开（吸气）→ 放起落架、滑翔降落归墟港跑道。马赫数从真空一路降到 0，正好是马赫数滑杆倒着走一遍 |
| 彩蛋（后期） | 剑形态演出结束后画面暗下，远处巨大机甲剪影伸手握住这把剑；字幕「剑已出鞘，执剑者何在？」「FIG.03 · 待解封」。剪影逆光、只露轮廓与朱红线；机甲须先构思到剪影层再放出 |
| 档案彩蛋（可选） | 「烛龙首飞从一号机库跑道起飞」（世界设定原文）：只做一张档案图或一段极短回放，不进主演出 |

### 7.1 镜头与视角（作者 2026-10-15，Z6 落地）

**原则：飞机不动，世界动。** 飞机始终在场景原点，速度、高度、天色、地球都由环境层表现（FIG.01 速度感的同一做法）。弹射段托架与飞机一起留在原点，滑轨、线圈与气闸环向后流走。好处：不出现超大坐标的抖动；镜头再怎么转，主角都在画面里；中途随时可以把视角交还观众。

**六个机位**（都挂在 `airframe` 上，跟着飞机走）：

| 机位 | 用途 |
|---|---|
| 展台 | 托架斜俯视；出击前与最后收束 |
| 追尾 | 机后上方，看飞机与前方的滑轨、气闸门、天空；弹射与返航滑翔的主镜头 |
| 侧跟 | 正侧面，看锁臂松开、脐带脱落、起落架收放、翼尖下折、喷口切换 |
| 仰拍 | 机腹下方斜后，看塞锥点火与尾焰、再入时机腹鳞片发光 |
| 座舱 | 飞行员眼位第一人称；闭眼时遮光盾合上，世界变成线框合成视景 |
| 远景 | 拉到很远：飞机只剩一个亮点和一道尾迹，天柱与地球弧占满画面；“大”就靠这一镜 |

**出击 · 入轨分镜**（约 40 s；连续运镜为主，硬切只放在有闪光或遮挡的瞬间，用来藏背景切换）：

| 段 | 画面 | 机位 | 环境 |
|---|---|---|---|
| 1 转正 | 转台转向对准滑轨；锁臂松开、脐带脱落；读数行「彈射位 3 · 就緒」 | 展台 → 侧跟 | 天门气闸环内舱，深蓝黑；舱灯沿滑轨逐盏亮起 |
| 2 开门 | 气闸门分开 | 追尾 | 门缝里先透进地球反光，门全开后是黑天、星点与脚下一弧地球 |
| 3 弹射 | 托架带飞机加速；线圈一段接一段亮起向后流走；读数 0 → 2 km/s | 追尾（视场角逐渐放宽）→ 侧跟 | 滑轨尽头冲出气闸环，**出口闪光处硬切** |
| 4 点火 | 脱离托架，塞锥后退、淡蓝尾焰点亮 | 仰拍 → 远景 | 远景里不周天柱的剪影与天门环，一道光点离开天柱（世界设定的“平台视角”） |
| 5 闭眼 | 遮光盾合上 | **硬切**座舱：舱内暗下 → 屏幕亮起线框地球与轨道线 | — |
| 6 入轨 | 姿态推进器小喷几下调姿 | 座舱 → 硬切回远景 → 慢慢推回展台机位 | 托架以一圈细光环的形式在飞机下方重新出现，地球弧在光环边缘 |

**返航分镜**（Z6 细化）：再入（仰拍，机腹琥珀光、等离子鞘）→ 展剑、睁眼（侧跟）→ 冲压 → 吸气（追尾，天色由黑转蓝，穿过一层云）→ 归墟港跑道降落（侧跟 → 展台，环境换成归墟港冷灰机库）。

**观众怎么“转视角”**：
- 演出中任何时候拖动画面 → 切到以飞机为中心的自由环绕，演出照常往下走；角落出现「回到镜头」，点一下用 0.8 s 缓动接回导演机位。
- 读数栏旁一排机位按钮（追尾 / 侧跟 / 仰拍 / 座舱 / 远景），点哪个切哪个，同样不打断演出。
- 时间轴可拖动，正放倒放都成立（与化剑同一要求）。

**做法要点**：机位路径用样条插值位置、注视点、视场角与侧倾；环境层由 `altitude` 与 `stage`（天门内舱 / 天门外 / 再入 / 大气 / 归墟港）两个参数驱动；录制模式用同一套机位，出视频时机位确定、可复现。

### 7.2 地台：天门弹射托架（作者 2026-10-15）

烛龙不用 FIG.01 的通用圆形转台，地台就是**天门的电磁弹射托架**：

| 项 | 设定 |
|---|---|
| 结构 | 圆形转台嵌在一段电磁滑轨的起点；平时观众拖动转台转着看，演出开始时转台转正对准滑轨——转台会转，在世界里有理由 |
| 托架 | 夹住机身的锁臂（4 个，前 2 后 2）；接机腹的供能脐带（与「銜燭」的脐带同一种接口语言）；尾部导流板；托架本身随弹射一起冲出、在滑轨尽头制动 |
| 滑轨 | 两条轨道夹一排线圈段，弹射时线圈逐段点亮（青 → 朱红），向前延伸到气闸门 |
| 背景 | 天门气闸环内舱，深蓝黑；正前方一道巨大的气闸门（分上下或左右两扇），门开后是黑天、星点、地球弧 |
| 标线与铭文 | 地面标线、对中线、站位编号；铭文用繁体，如「天門 · 四層 · 彈射位 3」 |
| 配色 | 天门以上转为深蓝黑（世界设定）；舱灯冷白，线圈点亮时青、满载时朱红 |
| 复用 | 每层不周有自己的展台：归墟港是跑道机库（FIG.01 一号机库保持原样不动），炼石台是机甲锻台；展台就是作品“住在哪一层”的标志，托架、锁臂、脐带等做法进 `arcseq-kit` |
| 弹射滑车 | 锁臂与脐带装在一辆**弹射滑车**上，滑车横卧在转台直径方向的槽里；转台转正后槽与滑轨对齐，滑车连同飞机驶入滑轨加速，在滑轨尽头制动后放开飞机 |
| 概念图 | `refs/concept/S1_天门弹射托架.png`（作者 2026-10-15 确认）。以它为准：转台嵌在滑轨起点、四个液压锁臂 + 机腹脐带（侧视的锁紧 / 松开两态）、尾后导流板、八角形两扇气闸门、滑轨两侧成排的舱灯与琥珀斜纹警示带、地面铭牌「天門 · 四層 · 彈射位 3」、三格分镜（锁臂松开 → 开门见地球 → 线圈由青到朱红逐段点亮）。不采信：图中机形（以 C2 与几何母版为准）；座舱盖向上掀开（开启方式另定）；锁臂作动筒的金黄色（改为金属本色，只在关节处留一点警告琥珀）；俯视画了两遍（中左那张只作俯视线稿参考）。定稿后按 WORKFLOW 走分色与拆图 |

## 8. 记录区（建模时追加）

### 8.1 概念图三视图之间的矛盾与取舍（Z0，2026-10-15）

量法：C2 俯视以全长 19 m 定比例（约 66 px/m），侧视约 43 px/m，前视以翼展 10.5 m 定（约 47 px/m）；站位 s 自机头尖向后。

| # | 部位 | 矛盾 | 取舍 |
|---|---|---|---|
| 1 | 机头光窗 | C2 俯视、侧视、前视里都画成一个整圆——平的圆窗不可能三个方向都是圆 | 做成机头尖上一颗**半嵌的球形传感器“眼珠”**（直径约 0.22 m），前半球是光窗，虹膜遮片朝前开合；三个方向都读成圆，“烛”的意象也更强。**复刻样板改**：眼珠退到 s 0.33（直径 0.172 m），前面是合拢成尖盖的虹膜六瓣，见 8.6 |
| 2 | 朱红棱线的起止 | 俯视从 s≈4.5 起、到机翼前缘转折处（s≈11）止；侧视从 s≈3.6 起、到翼根 s≈13 止；前视画到接近翼尖；DESIGN 写“从机头一路到机翼前缘” | **从光窗后 s≈0.6 起**，沿棱线到翼前缘转折处（以俯视为准）；点亮扫过时从机头到转折处。外翼前缘不画朱红（留给翼尖鳍的航行灯） |
| 3 | 垂尾外倾角与位置 | 前视：约 25° 外倾、根部在 y≈±2.0 m（翼面上）；俯视：投影面积大得像平尾（相当于外倾 60° 以上）、根部在后机身外缘 y≈±1.4 m；侧视：一片大垂尾 | **以前视的外倾 25° 为准、根部放在发动机段外缘 y≈±1.4 m（以俯视为准）**；俯视里的大投影不采信。化剑时向外转平成剑格，转轴在根部（Z2 定） |
| 4 | 翼尖小鳍 | 前视里翼尖鳍向下外撇约 60°（已呈下折状），俯视里画成向外的小梯形；DESIGN 写大气形态“立起”、剑形态“折平” | 大气形态：**外翼段平、翼尖鳍向下外撇 55°**（前视为准，读起来像蛟龙的爪）；剑形态折平。DESIGN 第 4 节“立起”改读为“撇出” |
| 5 | 鸭翼 | 俯视、侧视有（s≈5.3～6.4，侧视在棱线以下），前视没有画 | 保留鸭翼（俯视为准），**根部在棱线槽里、略低于棱线**（侧视为准）；前视遗漏不采信 |
| 6 | 机腹 | DESIGN“机腹完全平整”；侧视下轮廓是一条从机头斜下到 s≈10、再斜上到尾部的折线（龙骨很深）；前视腹底是平的梯形，两侧是斜下的下切面 | **横截面上腹底平整（乘波面）、纵向是一条缓折的龙骨线**（侧视为准，最深处在 s≈10）；棱线以下的下切面向内收到腹底平面 |

### 8.2 几何母版走哪条路（Z1 结论，待作者确认）

同一段机头（s 0～7.2 m：烛光窗眼珠、针状机头、切面前机身、眉骨、座舱盖、遮光盾滑轨、鸭翼、朱红棱线、鳞片瓦样片）做了两版，加一张 Cycles 渲染，三者并排见 `review/20261015-Z1-lookdev/`（ROUTE-*、CYCLES-*）。

**建议：几何母版走 Blender 建模脚本**（`blender/build.py`）。理由：化剑的转轴开槽、收纳槽、进气门这些“挖出来的”结构是布尔运算的天下，凸体拼不干净；AO 与细节贴图是本作品质感的两项基础，只有 Blender 路线能烘；同一份几何同时出网页与 Cycles 镜头。网页渲染仍是 ARCSEQ 引擎（五档明暗、分级线条、投影），Blender 只是几何与烘焙的工具，画面风格不变。
代价与对策：① Z2 开工前把网页改为直读二进制 GLB + 贴图文件（不再内联 JSON），整机页面目标 ≤ 4 MB；② 在 `blender/zl/check.py` 补穿插 / 扫掠检查（对应 FIG.01 的 `check.mjs`）；③ 机构数据（转轴空物体 `pivot.<id>`、行程）仍集中在几何母版脚本一处。代码凸体版 `src/geometry/nose.mjs` 保留作对照，Z2 起不再维护。

### 9.2 发动机：烛心组合动力（吸气 → 冲压 → 火箭）

| 项 | 设定 |
|---|---|
| 布置：两进、一心、三出 | 机腹宽扁进气口（中间隔板分两路，可调斜板 + 闭合门）→ 两条**左右并排**的 S 形进气道，各带一台折叠风扇（紧跟进气口）→ Y 形汇流腔 → 环形喷注环 → **烛心** → 旋转分流阀 → 两侧矩形二元喷口（左右并列）或中央塞锥 |

| 三种模式 | **吸气**（0～2.5 Ma）：斜板放下，风扇展开，空气经烛心加热，分流阀导向两侧喷口，塞锥关闭；**冲压**（2.5～6 Ma）：风扇折进道壁，斜板加陡，气流直通，两侧喷口收窄；**火箭**（大气层外）：进气门闭合，推进剂经喷注环注入，烛心满功率，两侧喷口闭合，塞锥后退露出线圈环形成磁喷管，只剩中央一道尾焰。出口变化“两侧 → 两侧收窄 → 只剩中央”是马赫数滑杆的视觉主线 |

## 10. 化剑要做细（作者 2026-10-15）

化剑不是「几个零件各转一下」，而是一台精密机器的动作。每一个大动作都拆成以下层次：

1. **解锁**：锁销缩回、密封条松开、整流盖板先打开让出空间（带小音效与读数）；
2. **主运动分段**：例如主翼先沿导轨后滑一小段，再回转，最后外段下折——不是一次单轴旋转；
3. **看得见的驱动**：作动筒伸缩、连杆联动、齿条带动，至少在特写和透视模式下可见；
4. **次级动作与错峰**：盖板、小鳍、密封片在主运动前后各自完成，相邻步骤略有重叠，像真实机械那样有先后和跟随；
5. **定位与确认**：锁销插回、盖板合拢、指示灯由青转朱红，读数「锁定 n / 12」；
6. **开锋**：全部锁定后，朱红棱线从剑尖一路亮到剑格，作为整段的收束。

其他要求：
- 化剑全过程约 12～16 s，可在演出中途手动干预，也可以用滑杆逐帧拖动（正放、倒放都成立）；
- 任何中间姿态不穿模、零件不凭空出现或消失（Z2 用正交俯视图逐步验证）；
- 声音逐步对应：解锁的轻响、作动筒的液压声、锁定的咔嗒、开锋的一声金属清鸣；
- 第一个零件（主翼回转）由 Claude 做完整样板并写进 PATTERNS，其余由 Codex sol 档照样板铺开。
