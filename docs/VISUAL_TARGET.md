# 视觉目标：A380 那种质感

最终画面要达到的质感，以 `refs/style-a380/` 里的五张截图为准。它们来自网上一段 A380 交互演示的录屏，**只作质感参照**（明暗、线条、细节密度、灯光、构图），不复制它的界面元素和任何素材，也不进入 `dist/` 或发布包。

G2 起每一轮视觉修改，都把我们的截图和 A1 / A3 放在一起比较；本文件末尾的清单逐项打勾。

## 精度分配（作者 2026-10-15：展示的做到极致，展示不到的下放精度）

精度跟着“观众最近能看多近”走。每个区域按页面允许的最近镜头（特写倍数）定精度，做到那个距离下经得起看就停，不往看不到的地方投入。

| 档 | 区域 | 标准 |
|---|---|---|
| **满精度** | 整机外观（转台主体，任何角度都能拉近看）；机头光窗；座舱与「銜燭」；烛心发动机（特写舱与剖视）；化剑关节（特写）；天门托架与开门那一镜；先导页面里出现的一切 | 按下面的「复刻标准」，叠图验收、反复打磨 |
| **中精度** | 剖视模式里看得到、但不能单独拉近特写的舱段内部（如机头航电舱、座舱后设备舱）；演出中镜头扫过但不停留的部位 | 一轮做完：体积、明暗、主要零件和走向对，像 A380 那样“安静但不空”；不追覆盖率、不逐件复刻 |
| **占位** | 任何镜头都看不到的地方：闭合舱门后面不会打开的舱室、蒙皮内侧被挡住的部分、远侧结构 | 只保留体积和装配关系（为了不穿模、剖切面封口），不建细节；能不建就不建 |

规则：
- 每加一个可拉近的特写或剖视入口，就把对应区域升档；没有入口的区域不升。
- 交审时注明每处改动属于哪一档；中精度和占位区不进叠图覆盖率指标。
- 性能预算优先保满精度区：占位区可以合并成少量网格、不进线条分级。

## 拆成规则

### 基调（2026-10-15 作者定：保留线条与光影，颜色放开）
FIG.01 的近乎单色是它自己的选择，原样保留不改。从烛龙起，**线条和光影是 ARCSEQ，颜色是作品自己的**。

保留（品牌骨架）：极细分级线条；平面块面明暗、窄条拼体积；深色舞台；作品角落小字；界面色固定（选中青 `#7BDBEC`、警告琥珀 `#F0BD83`）；一个画面一个主角。

每件作品开工先定一张**配色卡**，最多五个角色：
1. 主色：机身大面积，下分 3～4 级明暗，体积靠它读；
2. 辅色：第二块面（机腹、座舱等），与主色拉开明度或冷暖；
3. 标志色：一条线或一小块，作品的记忆点；
4. 能量色：尾焰、发光、再入，只在演出中出现；
5. 环境色：舞台 / 背景色调（机库、天空、太空皆可），必须够暗以托住线条。

唯一底线：**截图转灰度后，分区与体积依然读得出**（每轮明暗验收先看灰度）。

烛龙配色卡（草案，G1 前与作者确认）：
- 主色：哑光石墨灰（3～4 级）；
- 辅色：更暗偏冷的鳞片机腹，机翼前缘碳-碳最暗；
- 标志色：朱红棱线，线宽同主描边，偏暗不荧光；
- 能量色：再入时鳞片缝隙琥珀光，尾焰；
- 环境色：天门内舱与太空段深蓝黑（展台默认）；返航降落的归墟港段冷灰。
- 颜色随状态出现：未通电时朱红只亮三四成 → 通电从机头沿棱线点亮到翼尖 → 再入时机腹缝隙泛琥珀 → 化剑时朱红对齐成剑刃。

### 线条（最关键的“细”）
- **L0 外轮廓**：最亮的一级，但仍然细，大约 0.6～0.9 px（1440 宽截图下），不能变成粗描边。
- **L1 一级结构**：舱盖框、舱门、控制面分缝、进气唇口、喷口环，约 0.5 px，比外轮廓暗一档。
- **L2 次级工艺**：蒙皮拼缝、口盖、铆钉行，约 0.35～0.5 px，很淡，放大才明显。
- 所有线都贴着曲面走（像 A380 的舷窗排顺着机身弧度弯），端点落在边上或淡出，不悬空。
- 禁止给每个多边形描边；凸体之间的拼接缝不能露出来。

### 细节密度（“放大还有东西看”）
- 1× 看：一眼认出歼-20，整体安静。
- 2× 看：座舱盖框线、进气唇口与 DSI 鼓包、鸭翼转轴、控制面分缝、喷口锯齿边、起落架支柱和舱门都看得清。
- 4× 看：任意四分之一画面里都有可读的结构细节，例如锯齿形口盖边、铆钉行、喷口内的褶片、风扇舱门的铰链；大面积蒙皮保持干净，只留少量拼缝。
- 细节有疏密：集中在座舱、进气道、风扇舱门、喷管、起落架；不平均撒。

歼-20 上对应 A380 舷窗排的“签名细节”：锯齿形口盖与舱门边缘、喷口锯齿边、座舱盖框、DSI 鼓包、边条前缘。优先把这几样做到位。

### 灯光与地台
- 左红右绿航行灯、白色频闪：小色点加淡光晕，不做满屏泛光。
- 机体下方 halo 投影，起落架下有更深的接触阴影。
- 地台：比背景稍亮，外圈一圈极细刻度，地面引导线极淡。

### 构图
- 机体约占卡片宽度 70%，翼尖接近地台边缘；斜俯视约 30°。
- 角落小字（Fig、机型、读数）极小、低对比，不抢主体。
