# 设定卡 · FIG.02 烛龙

| 项 | 内容 |
|---|---|
| 名字 | 烛龙 |
| 类别 | 单座空天战机 / 可化剑 |
| 用途 | 跨越大气层的高速突防与轨道作战；剑形态用于高超音速与再入 |
| 与其他装备的关系 | 是一把“剑”：设定上由一台尚未公开的巨型机甲（FIG.03）执掌 |
| 背景一句话 | 睁眼为昼，在天穹之下翱翔；闭眼为夜，化剑刺穿大气层。 |
| 标志 | 机头烛光窗、朱红棱线、龙鳞防热瓦 |
| 外形要点（Z1） | 机头尖一颗球形“眼珠”（烛光窗，六片虹膜，通电琥珀光）；针状机头接切面前机身；座舱前一道 V 形眉骨（遮光盾收在里面）；朱红棱线沿最宽的棱边 |
| 配色卡（Z1） | 主色哑光石墨 `#202326`～`#3b3f42`；机腹 `#181c20`～`#2b3036`；朱红 `#c8412c`（发光 `#ff5a32`）；烛光 `#ffb060`；机库 `#111518`、太空 `#090d14` + 地球辉线 `#5aa2d4` |
| 状态 | Z1 视觉开发完成机头段样板，待作者门禁 |
