# 设定卡 · FIG.02 烛龙

| 项 | 内容 |
|---|---|
| 名字 | 烛龙 |
| 类别 | 单座空天战机 / 可化剑 |
| 用途 | 跨越大气层的高速突防与轨道作战；剑形态用于高超音速与再入 |
| 与其他装备的关系 | 是一把“剑”：设定上由一台尚未公开的巨型机甲（FIG.03）执掌 |
| 背景一句话 | 睁眼为昼，在天穹之下翱翔；闭眼为夜，化剑刺穿大气层。 |
| 标志 | 机头烛光窗、朱红棱线、龙鳞防热瓦 |
| 外形要点（Z1 复刻样板） | 机头一颗半嵌的球形“眼珠”（烛光窗，s 0.33，前面是合拢成尖盖的六片虹膜，通电琥珀微光）；单顶点棱锥切面前机身；座舱前一道 V 形眉骨（遮光盾两片帐篷形钛板收在里面）；朱红棱线沿屋面外沿；下切面是扁六边形蜂窝防热瓦 |
| 配色卡（Z1） | 主色哑光石墨 `#272b2e`～`#484d50`；机腹 `#1d2126`～`#343a40`；朱红 `#c8412c`（发光 `#ff5a32`）；烛光 `#9a5218`；机库 `#111518`、太空 `#090d14` + 地球辉线 `#5aa2d4` |
| 飞行员服 | 「衔烛」：抗荷服与全压服合一，化剑时同步披甲；接通时脊背朱红线与机身棱线一起亮（DESIGN 9.1.1） |
| 状态 | Z1 复刻样板（机头段 s 0～7.6 m）进行中 |
